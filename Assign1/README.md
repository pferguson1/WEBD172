# Assign1 - Node.js Hello Script

This assignment is a simple introductory Node.js program that prints a greeting to the console.

## Files

- `hello.js` - JavaScript file that runs in Node.js
- `hello.txt` - Text version of the code and basic run notes
- `Sceenshot1.docx` - Assignment screenshot/document file

## What the Script Does

The script:

- creates a variable named `studentName`
- stores the name `Phyllis`
- prints a greeting message to the console
- confirms that JavaScript is running with Node.js

## Code Behavior

When `hello.js` runs, it outputs:

```text
Hello, Phyllis
JavaScript is running with Node.js!
```

## Requirements

- Node.js installed
- VS Code or another code editor

## How to Run

1. Open a terminal.
2. Change to the `Assign1` folder.
3. Run:

```bash
node hello.js
```

## Learning Goal

This assignment demonstrates:

- basic JavaScript syntax
- variable creation
- console output with `console.log()`
- running a JavaScript file with Node.js
